## 原型接入

1. 读取 `manifest.json` 并校验 `schema_version`；
2. 加载 manifest 中列出的数据文件；
3. 以 `resource_id`、`edge_id` 及各类稳定 ID 建立引用索引；
4. 按 `playback/storyboard.json` 的场景顺序驱动页面；
5. 第 5 幕从原始文件读取实际告警字段、日志原文、指纹和 KPI 点；
6. 第 8 幕只降暗展示未来修复能力，不显示已执行或成功。

所有数据均为原型 Mock 数据，不代表真实环境实测结果。
