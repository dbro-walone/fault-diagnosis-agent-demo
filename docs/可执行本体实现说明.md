# 故障运维可执行本体实现说明

本文记录 Issue #1 的实现边界。既有 `docs/` 基线文档仍是行为契约；本文只说明代码如何承载该契约。

## 统一模型

- `OntologyObject` 是拓扑、知识、诊断、影响和审计视图共享的稳定身份。设备、知识、Fact、Evidence、Candidate、Plan、Task、Function Call、Action Proposal、Decision 与 Scenario 都使用同一对象协议。
- `OntologyLink` 表达对象关系。五类 Lens 只过滤同一快照，不复制对象，也不维护各自状态。
- 基础模型由 topology、knowledge graph 和 cross-layer mapping 适配成只读 Registry。
- Case 被加载为独立 `ScenarioOverlay`。它只能新增带相同 `scenarioId` 的对象与链接，不能覆盖基础对象。

## 执行边界

- `RuntimeEvent` 是诊断状态的唯一写协议；回放或跳转均从事件日志确定性投影。
- Function 与 Skill 只读并只返回事实载荷；Fact 由 Runtime 写入本体。
- Function、Skill 与 Action 定义来自单一 Catalog。Scenario 只引用稳定 ID；确需 Case-local 能力时，通过 `catalog.overlay` 注册一次，Object View、Runtime 与校验器解析同一快照。
- Planner Task 显式声明 `FUNCTION_CALL` 或 `ACTION_PROPOSAL`。Action Proposal 始终需要审批，演示运行时不会执行运维动作。
- Decision 只有在终态门控事件中创建，并保存 Candidate、Evidence、影响路径和恢复路径的对象级血缘。
- Runtime 在应用 Decision 前从当前 Session 重算支持分、最小证据类别、Function/Fact 血缘、竞争候选、冲突、时序及逐段影响/恢复 Link；Scenario 中同名布尔值不构成授权。
- 播放控制器分别维护 `liveHead` 与 `replayCursor`。历史查看不会把尚未到达的 Scenario 定义事件当作“最新”。

## 前端投影

- TOPOLOGY：资产、路径、冗余及跨层类型映射。
- KNOWLEDGE：对象类型、现象、故障模式、机制、证据规则与案例。
- DIAGNOSIS：Scenario、Fact、Evidence、Candidate、Plan、Task、Function Call 与 Decision。
- IMPACT：已证明的影响与恢复路径。
- AUDIT：Function 原始结果、计划差异、Action Proposal 与 Decision 血缘。

Object Set、Search Around 和 Object View 都查询同一个 Registry 快照；WebGL 双平面也由同一 Lens 投影生成。

## 自动化验证

执行 `npm test`。测试覆盖：

- 对象身份唯一、链接完整与 Scenario 隔离；
- 五类 Lens 的对象和链接过滤；
- 初始态不泄露根因、Runtime Event 唯一写入口与确定性回放；
- Function Call / Action Proposal / Skill 读写边界；
- Decision 终态门控、证据血缘、影响路径和恢复路径；
- `SymptomNormalizer -> CaseRouter -> Case` 路由链。

## 开发依赖决策

### `vitest`

- 用途：执行 Runtime 协议、Scenario 负例、Lens 防泄露、路由和回放控制器的确定性回归测试；仅属于开发依赖，不进入生产静态页面。
- 替代方案：Node.js 内置 `node:test` 配合 TypeScript 转译器，或使用仓库外部测试运行器。前者会增加 ESM、JSON import 和 Vite alias 的适配代码，因此当前保留 Vitest。
- 许可证：Vitest 核心为 MIT；发布包所列捆绑依赖还包含 MIT、BSD-3-Clause 与 ISC。
- 移除条件：测试迁移到统一的平台级运行器，且该运行器能原生覆盖 TypeScript、Vite alias、JSON fixture 与浏览器组件测试时移除。

### `@types/node`

- 用途：为 `vite.config.ts` 中的 `path`、`fs`、`__dirname` 等 Node 构建期 API 提供类型；仅在开发和构建期使用。
- 替代方案：将构建配置改为无 Node API 的纯 Vite 配置，或维护最小 ambient declaration。手写声明容易与 Node API 漂移，当前不采用。
- 许可证：MIT。
- 移除条件：TypeScript 配置和构建脚本不再引用 Node API，或工具链正式内置所需类型时移除。
