# 远程复制滞后 Mock Case

该数据包遵循 Case V1.0 目录和字段规范，用于演示生产存储 Storage-A 到容灾存储 Storage-B 的复制链路丢包/拥塞，造成有效复制吞吐下降、积压增长和 RPO 超标的诊断过程。

## 故障主线

`复制WAN链路拥塞/丢包 → 协议重传激增 → 有效复制吞吐下降 → 待复制数据积压 → RPO升至720s → 会话降级 → 链路恢复后积压与RPO收敛`

关键时间：

- 16:03:00：WAN链路拥塞开始；
- 16:03:30：丢包率升至4.8%，重传升至3,200/s；
- 16:04:00：复制吞吐降至0.35GB/s；
- 16:08:00：积压升至96GB，RPO升至720s；
- 16:10:00：链路恢复；
- 16:14:00：RPO收敛至45s。

本地生产 LUN 时延保持 2.1～2.5ms，影响是容灾保护能力下降，而非本地业务中断。所有数据均为 Mock 数据。
